# 首页热词

日历下方显示「今日热词」（历史日期为「当日热词」），最多两词；点击查看解释、新意和原始来源。下面的每日简报压缩为更新时间、订阅渠道和入口，移除机器人插图。沿用漫画风和双词卡片布局。

卡片标注每个词的有效来源数量，详情中列出来源网站、原始发表日期和可点击的原文标题。「来源与算法」入口公开候选提取、证据门槛、排除规则、50% / 30% / 20% 排序权重及采样局限。

热词详情同时展示 AI 基于所引原文生成的中文、英文解释，标明两种语言，无需切换站点语言。历史新词沿用其保存的双语解释和证据。

「历史新词」按入选日期倒序展示已保存的非空记录，默认从当前日历日期向前，每页最多 14 个日期，可继续查看更早记录。每个历史词可打开当时的解释和来源，允许同一词在不同日期重复入选；不生成或补造过去的词。

## 筛选与更新

- 调度时区沿用站点设置。后台启动时筛选一次，随后每小时第 20 分钟筛选，成功结果写入 `dashboard_new_words` 当日记录。已有非空结果缓存 50 分钟；空结果不阻止启动补齐。两种触发复用同一个单实例调度任务，停用任务时均不运行；浏览请求只读结果，不触发模型调用。
- 候选来自近 7 天的官方公告、技术博客、中英文 AI 新闻、Hacker News、启用时的 X 与论文。无需搜索 API 密钥，使用 DDGS 的 Bing/Yahoo 公开检索，覆盖 AI 新功能、开发者工具、中文新玩法及官方发布；再为最多八个候选查询独立讨论和更早的提及。没有本站文档时也可凭已核验的站外资料选词。
- 检索结果只提供原文链接，搜索摘要、搜索结果日期、网页更新时间和入库时间不能充当证据。报道中指向 arXiv、DOI、OpenReview、OpenAI、Anthropic、Google、Mistral、Hugging Face、Qwen、Moonshot 的原始发布链接也会被抓取，每页最多追溯两个链接。抓取原文后读取发表日期元数据或文章 JSON-LD；arXiv 修订版追溯 v1 提交日期。缺少原始日期、发布时间在未来或正文不足的页面弃用。
- 本站每个来源最多读取 120 篇；从 AI 新闻与 HN 线索中补抓最多 12 个原文页面，完整原文优先于已有的短标题。模型按站外网页、新闻、HN、X、论文交替取样，每类最多 8 篇；同一发布者最多占两篇（论文渠道四篇），已识别官方账号优先，避免论文或单个账号占满候选上下文。使用低推理预算避免后台抽词超时。单轮公开检索最多抓取 64 个去重网页，发现阶段使用至多 32 个名额，保留其余名额验证独立讨论。检索并发为 2、网页抓取并发为 4；发现与候选核验各有 100 秒上限，网页单次最多 15 秒、1 MiB 和四次重定向。每一跳校验并固定公网 IP，拒绝混合内外网 DNS、私网地址、带凭据 URL 及非标准端口。
- 模型提名具名的 AI 新功能、新玩法、新方法，明确排除非 AI 科技、普通硬件、金融、单独产品名与版本号。候选内部区分 feature、workflow、method；必须提供有原文资格的资料 ID，以及包含术语和提出/发布语义的连续逐字引句。新闻与 HN 的外链标题仅是线索。服务端核验引句（只归一化空白及标点前的 HTML 排版空格），检查 AI 语境；网页推荐阅读与评论组件不参与提及计数或原文链接追溯。
- 硬性排除 Claude Code、MCP、多模态、智能体、RAG 等常见旧词及别名。方法类候选查询本站与公开网页历史，7 天之前已有同义术语即淘汰；具体功能和玩法允许名称更早存在，但必须有本周的新进展，不宣称“全网首次出现”。短大写缩写须按原文大小写匹配，避免把 WISE 误判成旧论文中的 layer-wise。新颖性存疑时允许不选。
- 至少两篇去重资料、两个发布者，最近 48 小时仍有提及。相同 URL、相同标题、相同的完整长正文、纯转发不能重复计数。聚合站和普通 X 账号不能充当一手出处；feature/workflow 可引用已索引的 OpenAI、ChatGPT、AnthropicAI、ClaudeAI、Google、GoogleAI、GoogleDeepMind、GeminiApp 官方 X 发布，仍需正文逐字引句和独立讨论。method 必须回到网页或论文原文。
- 通过证据门槛后排序：50% 为独立发布者覆盖（六家封顶），30% 为按来源归一化的提及占比增长（近 24 小时相对前 6 天，加一平滑、最高 3），20% 为一手发布的新鲜度。已识别的 OpenAI、Anthropic、Google 官网与官方账号按同一发布者计数；引用优先覆盖不同发布者。相近分数取十分位，同分延续已有顺序。分数反映所采样资料中的热度，不是全网讨论量统计。
- 不强制每天换词：本轮没有新候选时可保留当天或前一天已验证的词，但仍须在 7 天窗口内、最近 48 小时有提及，且来源仍有效。搜索结果波动不会直接清空卡片；确实没有有效新词时显示空状态，不用热门旧词补位。

热点组织参考 AIHOT 公开展示的多来源事件聚合与时间线，以上权重是本站规则，并非 AIHOT 未公开的评分公式。运行中的站点直接检索与核验原始来源，不同步或转发 AIHOT 的聚合数据；AIHOT Skill 单独安装在操作者的个人技能目录。

## 读接口与异常

`GET /api/dashboard/new-words?date=YYYY-MM-DD`，省略日期时读取今天；未来日期及无效日期返回 422。

`GET /api/dashboard/new-words/history?before=YYYY-MM-DD&limit=14` 返回 `items`（沿用单日公开快照结构）与 `next_before`。日期游标为排他上界，默认包含今天；`limit` 范围为 1～31。只读实际保存的非空日期，逐项复用来源有效性校验；不会因为历史入口而调用模型或发起外网抓取。已失效的词不返回，但翻页游标仍按扫描日期推进，避免漏页或重复。

返回 `date`、`generated_at`、`status`（`ready` / `pending` / `empty`）、`items`。每项包含稳定 ID、术语、中英解释及新意、所引资料最早日期和最多六条出处。站外引用使用 `source: "web"`，保留相同的公开字段，不要求出现在本站文档表中。后台快照额外保存抓取时间和基于规范化 URL 的 ID，读接口验证其与发表日期、生成时间相符，不返回内部校验字段。

本站引用读取时仍复核文档存在且来源启用；无效站外引用也会被移除。主出处缺失或已不足两个发布者时隐藏该词。读接口不访问站外网页、不调用模型，也不把站外资料自动写入资讯库。

历史记录不回填、不借用今天的词。模型超时、格式错误或缺少可用资料不覆盖当天成功结果；公开检索不可用且没有选出新结果时也保留当天已有热词。检索正常、没有新候选且旧词已失效时更新为空。网页请求失败保留同日已显示的词并提供重试，换日期立即清除旧词。调度失败沿用现有告警通道，可从调度配置中调整或停用 `dashboard_new_words`。

Compose 的 `NO_PROXY` / `no_proxy` 包含本站模型中转域名 `api.aigcnews.cn`，避免将本地可达的中转请求送入公共检索代理。公开检索与原文抓取仍使用 `OUTBOUND_PROXY`；原文传输用 libcurl `CONNECT_TO` 固定连接地址，同时保留原域名的 TLS/SNI 校验。
