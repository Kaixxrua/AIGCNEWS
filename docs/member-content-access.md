# 搜索与内容的登录要求

网站使用免费账号登录状态判断权限，不要求付费会员。

| 入口 | 未登录 | 已登录 |
| --- | --- | --- |
| 项目库第一页 | 可浏览，每页最多 24 项 | 沿用原分页参数 |
| 项目库搜索、第二页及后续页 | 提示登录，不提供搜索试用 | 可使用 |
| 站内速查 | 打开时提示登录 | 可使用 |
| 简报 | 可阅读预览 | 可阅读全文 |

登录提示保留项目搜索词、页码或简报日期与类型；登录完成后继续对应操作。
简报预览只返回正文前部，最多 1200 字符且不超过完整正文的一半，
随后附加省略号。退出登录时清除已加载的受限内容，旧请求不能重新写回。

## REST 行为变化

- `GET /api/projects`：非空 `q` 或 `page > 1` 需要有效的用户令牌；
  匿名第一页将 `page_size` 限制为 24。分类、排序仍可使用。
- `GET /api/search`、`GET /api/report/latest`、
  `GET /api/report/{数字 id}`：匿名或无效令牌返回 401。
- 新增 `GET /api/report/preview`：公开预览，支持 `source`、`date`、
  `locale`，返回 `is_preview: true`。匿名简报调用方应迁移到此接口；
  全文调用方需携带有效的 Bearer 用户令牌。
- 简报全文响应使用 `Cache-Control: private, no-store` 和
  `Vary: Authorization`，避免共享缓存保存全文。

此次调整仅针对网站入口。独立的 `/api/v1`、MCP、带订阅令牌的 RSS
沿用原有授权和响应契约。

## 验证

`backend/tests/test_member_content_access.py` 覆盖匿名及无效令牌拦截、
分页上限、双语预览截取、全文缓存头与登录用户参数。
前端控制器及组件测试覆盖登录恢复、延迟响应、退出登录清理，以及首次
打开站内速查时的登录判断。
