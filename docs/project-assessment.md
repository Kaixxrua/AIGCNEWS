# 项目试用判断（已下线）

试用判断功能已撤下：项目列表、热榜、预览和详情不再展示评估内容，筛选栏移除“可评估试用”。新项目富化只生成分类、双语介绍与标签；每日流水线停止旧项目补评，不再为评估调用模型。

## 兼容行为

- 旧 `/projects?scope=screened` 链接切换到全部项目，并保留其搜索、分类和排序条件。
- REST 继续接受 `scope=screened`，按 `all` 查询并返回 `scope: "all"`；列表和关键词检索都不再按历史评估过滤。
- 项目响应保留可空 `assessment` 字段，固定返回 `null`；流水线结果保留 `assessment: {"status": "disabled"}`。
- 保留历史数据库迁移和 `assessment_json` 列，不删除数据；普通富化不再写入或覆盖该列。历史评估不参与查询、筛选或展示。
- 项目收录、热度、分类、搜索、人工推荐、收藏与 MCP 输出保持原有行为。

## 验证

回归验证覆盖新项目正常富化且忽略模型返回的旧评估字段、每日任务停止补评、历史数据不再输出、旧筛选链接回退，以及真实 PostgreSQL 中列表、关键词检索和正常富化保留历史数据。
