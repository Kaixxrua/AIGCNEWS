## 统一学习边界

- 不要求编写 Java、Python、TypeScript、Go 或 SQL；
- 不要求通读 AIGCNEWS 源码；
- 不要求把学习任务变成项目开发任务；
- 允许阅读架构图、接口输入输出、配置含义和运行现象；
- 练习优先使用自然语言、表格、流程图和架构图；
- 所有项目数字必须区分“当前事实”和“练习假设”。

## 统一自测方法

每次自测必须离开材料完成。建议按以下顺序：

1. 先写答案或画图，不要先看参考答案；
2. 对照参考答案，用颜色标出“漏掉的约束、代价、风险和验证”；
3. 给错题归因：概念不清、边界混淆、审题错误、记忆遗漏；
4. 48 小时后重做一次；
5. 只有重做仍能说清原因，才算真正掌握。

### 统一评分口径

除选择题外，主观题按四类证据评分：

| 维度 | 合格表现 |
|---|---|
| 概念 | 定义准确，能说明适用边界 |
| 结构 | 图或文字有清晰的输入、处理、存储、输出和边界 |
| 权衡 | 至少给出一个替代方案及其代价 |
| 闭环 | 覆盖故障、降级、监控、恢复或验证 |

答案不是唯一方案。只要覆盖题目约束、方案合理、取舍自洽并交代风险，就可以与参考答案不同。

## 什么时候暂停、回补和转段

- 连续两次复述都不能说明“是什么、解决什么、代价是什么”：回到该主题的概念解释；
- 自测低于通过线：48 小时后重做同一题，仍低于通过线才回看章节；
- 同一错因在 3 道题出现：建立专门对比卡，不要继续堆新知识；
- 达到专题手册的阶段验收，且能完成总路线的对应产出，才进入下一册；
- 时间不足时，保留“必学”和自测，删除“选学”，不要删除自测。
