# 交接停止边界

依据：[本地交付控制器 — 开发任务的停止边界](../local-delivery.md#开发任务的停止边界)。本文仅概括原文，不新增配置或门禁。

- **允许停止**：本地影响面验证通过，自动提交并推送后，精确 SHA 已入队、创建时归属一致，且通知控制器在最近 120 秒核实唤醒通道，Stop hook 才允许结束。
- **交接表述**：报告“已交接自动化”，不等待 CI、合并或发布完成，不把交接成功表述为已上线。
- **不能冒充成功**：推送失败、归属未知、唤醒通道未就绪或已有待修复失败，均不能报告交接成功。
- **后续处理**：成功只更新看板，失败才唤醒；修复提交后再次交接。发布失败只通知精确 release SHA 对应的承接任务。
- **归属与唤醒**：新 AO 任务由 `dev_session.start` 核对 provider thread ID 并自动激活绑定；旧任务不能按标题猜测绑定。存在 AO 绑定时绝不跨通道回退；发送超时保存 `unconfirmed`，不盲目重发。
- **终态与例外**：已上线的真实生产证据仍可作为终态放行依据；基础设施修复任务的显式全链路验收要求保持。
