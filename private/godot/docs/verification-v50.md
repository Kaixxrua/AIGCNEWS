# v50 村庄、转动风车与回归检查

2026-09-09。用户已将标准调整为“整体不违和”，不再要求严格 1:1。本轮完成独立村庄及两个不同叶轮接入；最新反馈另指出云缺乏体积、村庄/城堡太糊、夜景过暗，留给下一版修正，不把技术通过当作这三点已解决。

## 制作与实现

修改前 v49 快照 179 个源码文件逐个哈希一致。内置 imagegen 一批四并发，显式提示“八方旅人2”，选真透明 C；完整提示词及源哈希见 `asset-generation-v50.md`。三个图集区域各用一次，旧村庄保留在磁盘而不再导出。当前 68 个不重复图像元素。

`meadow_village_builder.gd` 将村庄放在 z=-170 米，宽 70.657、高 15.135 米，相对原图高宽比仅 1.023 倍。65 个基脚由真实网格取点，再用物理射线复查，误差最大 0.0250 米。只下部 0.24 UV 基脚带贴地，楼房主体和两个轴心固定。首次 z=-127 方案会拉长到 1.419 倍，断言拒绝；改深度而未放宽保护。诊断日志保留。

两个独特叶轮分别直径 8.8/8.0 米，围绕源图实测圆轴心转动，速度 0.27/0.21 rad/s。它们消费天气共享时钟；暂停冻结、日夜不重置相位、恢复继续转动，建筑不随风。独立测试检查实际节点变换、固定轴心、昼夜暂停恢复，而不只检查计算公式。
