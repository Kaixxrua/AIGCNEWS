# v53：可读的随机生物、夜间灵鹿与云层漂移

## 范围与回退

本轮响应动物太小、飞龙尺寸与固定绕圈、云看不出运动，以及夜间发光动物的追加要求。相机、地形、主路、8.4m Boss空间、远景清晰度和已有月光/窗口灯均保留。v52 PCK SHA-256仍为 `57F544AA1701AFDAC6A618C960B330C084F21EC2A942DD37725FF9B8FF3370E8`，旧导出未被覆盖。

## 实现

- 野兔/鹿/狐狸的图集展示高度从0.63/1.36/0.73m调整为1.05/2.15/1.20m，并把鹿、狐狸移到较近的开阔活动区；不关闭正常远近透视。
- 四个地面个体按各自的安全栖息区随机选目的地，随机停留与速度，沿实际地形/岩石三角面落脚。路径避开道路、河流、Boss空间、岩块、树根和其他可见动物。每次载入随机种子不同，专项测试固定种子以复现。
- 飞龙固定25m图集翼展，三维目标在z=-385..-300m高空范围内随机取点，使用连续三次B样条和弧速近似。根据用户追加“不要贴地”的反馈，把肩部投影进一步抬至画幅高度7.4%–9.0%，专项检查全过程世界高度大于45m；为完整上拍留顶边空间。前后距离、高度及转向变化，转身时收窄侧面轮廓并轻微倾斜。不是屏幕图标或周期椭圆。
- 只在夜间出现的月辉灵鹿：四并发选B真透明四帧图，73.57%全透明、四格边缘无越界。按四帧实测蹄尖设置脚锚。鹿角/少量冷色毛纹发光，另有随身体移动的冷色OmniLight及带深度测试的小光晕，不把全身做成霓虹贴纸。
- 近云速度0.55..0.85，远云0.38..0.60；减小过圆轮廓，加少量随云移动的体积侵蚀，循环边界放在各层可见范围之外。运动仍来自可暂停的 `meadow_clock`。
