# v82 — 夜空增加细星

后续用户反馈：实际网页里看不见星星。虽然下面记录的原生 2K 局部复核通过，但普通显示尺度的可见度没有满足用户要求；v82 不作为最终星空验收版本，v83 继续提高主星可读性。保留原测试和评审结论，不追改当时证据。

用户要求：夜景增加星星，后续截图采用原生 2560×1440。相对 v81 只改变天空着色器中的星点路径；保留暖日光、月光、云形状/运动、曝光、水与景深。本轮接受星空局部外观，不代表整体场景美术目标完成。

## 实现和范围

- 固定角坐标中的抖动星位、变化的疏密/大小/亮度；按当前约 9° 的可见低空设计，不新增贴图、场景光源或星点循环。
- 地平线附近渐弱，入夜渐入、天亮渐出；云仍在星点之后合成，厚云和地景遮挡保留。约 6% 的较亮星点使用共享可暂停时钟轻微闪烁，位置不随时钟漂移。
- 使用连续角坐标导数过滤细小星点，并限制支撑半径与能量；保持原有天空底色。新增星点可能自然进入环境反射，不宣称水像素逐点完全相同。
- 天空源 SHA-256 `b089890a1c830bdb6ffd84d1815b9a0c1f089ea7b6916deb19cc187f46f6880f`。原天空和 v81 weather 原件保存在 `artifacts/v82/meadow_sky.before-stars.gdshader`、`meadow_weather.v81-baseline.gd`。恢复工程的 Git 根目录仍不正确，按工作区隔离技能沿用本地版本快照/独立导出，不写 Git 或恢复源。
