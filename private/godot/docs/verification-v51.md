# v51 云体积、清晰远景、月光、暖灯与透明河水

2026-09-09。依据用户连续反馈修改：云过于扁平；远处村庄/城堡太糊；夜景过暗且建筑没有灯；整体提亮后道路不自然；河水太蓝、不够透明；希望灯有光晕。仍以整体协调为标准，不要求严格 1:1。

## 实现

### 云与远景

云从二维噪声的近乎单色混合改成有限厚度的三维密度场，24 步透射累积、两级密度噪声和一次朝向光源的遮挡采样，区分亮面、暗底与透光边缘。最后尝试固定空间采样偏移打散条带，但 rev=6 实际网页仍有明显颗粒，不能视为云的美术验收通过。云平移仍由 meadow_clock 驱动，昼夜由 meadow_night 统一着色；不是完整气象模拟或引擎体积雾。

最初 12 步出现条带；48 步全分辨率在当前窄网页短采样降到 48/28/30 FPS。曾尝试独立半分辨率 sky 通道，但实际网页天空显示异常，已撤回，不使用该通道。最后改为两级密度、24 步及固定空间采样偏移，性能与最终目视仍以以下实际网页记录为准。

远景景深起止由 86–205 米改为 215–390 米，最大远景半径由 1.8 降到 0.35 像素（1080 渲染高度基准）。村庄基点实际 view-depth=205.16 米，对应 0；城镇 288.47 米，对应 0.1333 像素。近景 23–43 米、最大 8 像素不改。建筑专用 mip bias=-0.45，叶轮=-0.20，保留 mipmaps，不给全部植被强行锐化。源 PNG 没有重画或改写。

### 月夜与灯光

首轮月光 1.10、环境补光 0.62 导致道路过亮，按用户反馈重调：月光能量 0.95，旋转 (-28,-145,0)，偏冷方向光；环境补光 0.50，曝光 1.20，夜雾 0.00075。土路在夜间降低反射亮度并偏冷，不再作为整条泛白的亮带；白天参数保持。远景原画夜间补光提高以保留建筑层次，而不是把建筑所有面变成暖色。

在实际图上挑选 32 个城堡/城镇与 20 个村庄窗户/入口，以源图 UV 锚定暖色发光；它们不在叶轮上。所有中心经真实 alpha>0.9 和图集区域检查。Shader 夜间淡入，白天不发光；只有很轻的固定时钟波动。这里是远景窗面发光，不是完整房间模型与室内光照模拟。

52 个窗光晕从建筑实际网格 UV 三角形反算世界坐标，用一个 MultiMesh 批量绘制；路边灯笼另有一张柔和光晕。软边加色、深度测试、不写深度，并共用昼夜和暂停时钟；不是遮住整幅画面的发光贴层。原灯笼的实际 OmniLight 暖光仍保留。新 halo shader 显式加入资源导出清单，防止源码能跑而 Web 缺资源。

### 透明河水

原河水是不透明蓝色材质。当前使用真正 alpha 混合，读取实际河床深度：浅/深基础不透明度 0.18/0.46，另加掠射角反射与少量泡沫，最终限制 0.12–0.72。底色改为低饱和灰绿；仍有随河湾流向组织的法线、水纹与反射。不是简单整片蓝色降饱和，也不是完整折射或流体模拟。

连续地形中的实际水下河床改成砂砾色和克制的流动光纹；河床区域使用和几何完全相同的十个弯道点、半宽公式，避免把前景崖底误当河床。另有 72 个程序化水下石头，一个批次绘制；最高点 -2.518 米，水面 -1.05 米，均不进入可行走区。原 2,067 块地表/岸边岩石未增删，72 块为额外水下几何，不是复制图像道具。

透明水在 render_priority=127 绘制，晚于景深屏幕效果的 126，否则 Godot 在不透明阶段复制的屏幕会盖掉水面。桥、树和河岸仍通过实际深度遮挡水。水面因此不参与这层屏幕景深/调色，保持清晰；深度调试 G 看到的是不透明河床，透明水和光晕会随后合成。

## 验证状态

20260909-135526 最终九阶段构建均结束，退出 0，源码、天气、草甸、树冠、村庄、气氛检查及独立 PCK 启动通过；无最终错误日志。实际 rev=6 Web 中可见透出石头的水面、灯窗与暖光晕，暂停后昼夜可切换。但云有颗粒、主要近景树过度虚化，用户仍认为夜景偏暗、远景偏糊及物件贴片感明显，因此 v51 不是最终视觉验收版本，后续由 v52 继续修正。修改前月夜保存在 `artifacts/v51/night-rev6-before-v52.jpg`。v52 修改前已保存 198 文件源码副本 `artifacts/v51/source-before-v52-20260909/`，逐文件 SHA256 一致。

开发过程中的失败记录保留：默认未设置的 shader 参数在无窗口模式返回 null，现显式设置 window_count=0；新增测试的浮点相等改为近似比较；一版漏打包 halo shader，已显式加入导出清单并验证独立 PCK 能启动；半分辨率云显示异常已撤回。不要把早期失败日志当作最终版本，也不要声称所有尝试从未报错。

## 保留边界

相机、中央行走路线、Boss 空地、地形碰撞、桥和各现有图像资产的位置不变。68 个图像元素仍各用一次；无新引擎，无额外图片下载，不修改恢复源。旧 v50 的 190 文件源码快照和导出保留。正式人物、寻路、怪物与战斗未在此轮实现。
