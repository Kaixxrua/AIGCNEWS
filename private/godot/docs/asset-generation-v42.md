Use case: stylized-concept.
资产用途：Godot 3D 草原台地岩壁的四块独立表面美术图集。明确风格：八方旅人2 / Octopath Traveler II，HD-2D，细腻像素簇与可信的微缩景观岩石质感。

生成横向 3:1 长图，四条极长而低的天然石灰岩正面纹理自上至下排列，一列四行。每行是独一无二、完整独立的岩面条带，宽约高的12至14倍，每条之间至少20像素真正透明空隙，四周也有透明余量。RGBA PNG，空白必须 alpha=0，绝不绘制棋盘格或白色灰色底板，不要任何文字、编号、边框。

画的是天然草原台地的正面岩壁，不是整片风景，不是等距视角的厚方块，不是砌砖墙、柱子、蜂窝、铺路石或规则栅栏。正对岩面的正交视角，仅看到岩面与顶沿少量薄苔和细草根，不要画宽阔草坪顶面，不含天空、山城、树木、桥梁或水面。每条包含至少40到55个大小不等、横竖交错、有轻微凸出和嵌入的天然碎裂岩面；2至4个断续的自然层理，不能画成整齐水平砖缝。形态以圆钝破角的浅灰米色石灰岩为主，部分长扁岩片、部分高短岩块，局部有崩落小缺口和深青灰裂隙，比例多变、风化可信。石头色面要清楚、细腻，有矿物斑点和苔痕，不要大块平涂三角形。岩体不能像一堆孤立石块没有连续基岩。

色彩：暖米灰、柔和蜂蜜色日晒面，深灰绿/微蓝灰缝隙，极少量暗橄榄苔和细根；禁止荧光黄、橙红、纯白、雪、黑色描边。晴天暖阳来自右上，但表面整体亮度克制，不要强烈镜面高光和摄影阴影背景，游戏里会统一受光。像八方旅人2晴天草原画面中的自然岩层，细碎有层次而非低多边形模型截图。四条均有独特岩纹，不能复制翻转同一条：
第一条：较厚而圆钝的乱裂石灰岩，顶部有短短暗绿草根。
第二条：更细碎一些的薄层天然岩片，与少数斜向裂缝。
第三条：少量粗块嵌在连续基岩中，横向宽裂与小崩口，不规则苔点。
第四条：前景用的侵蚀裂岩，凹凸稍大、深缝更有层次，但仍是连续长条正面。

## 四个分支

### A

版本 A：强调朴素自然的灰米色矿物面、磨圆边角与深灰绿缝，不规则层理和自然碎裂。

### B

版本 B：更接近原野中的低矮石灰岩断层，明暗集中于宽窄变化的裂口，细像素簇，不要铺满高光。

### C

版本 C：强调八方旅人2的微缩立体岩石质感，温暖浅岩面和深橄榄阴面并存，复杂但不花哨。

### D

版本 D：层理更断续，崩落边角更自然，少许细草根嵌入缝中，沉稳的金灰色，不要均匀砌筑感。

## 检查工具

`tools/audit_strip_atlas.gd` 只读扫描每个像素的 alpha、寻找一列四行的真实透明分隔并输出边界。没有调用 Python、CLI 图像 API 或外部抠图服务。界面中的红色透明预览需与实际 alpha 检查区别对待，最终还要在游戏材质中复核。
