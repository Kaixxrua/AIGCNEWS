# v61：岩坡缺口、斜裂块体与统一石材

2026-09-09。承接v58加载优化、v59河岸和v60草土/投影修正，继续处理左侧台地像整条贴片、石材与草坡不协调的问题。本版是进一步打磨，不代表整幅美术已经达到参考。

## 实际修改

- 三层左台地各有两处确定的侵蚀鞍部；真实高度场降低坡肩、内收边界，岩壁和岩沿草皮在缺口处停止生成。不是在岩壁上盖草图。第四处小丘的原坡肩宽度保留；相机、河道中心线、主路与Boss区不改。
- 左岩层凸块不再按固定水平层放置。沿整个断面取不同高度，宽窄、厚薄、埋入量不同，倾斜最多约27.5°，减少像砌墙的横排。前景实体崖沿仍保留，草皮内缘与实际地形相接。
- 两轮内置ImageGen，每轮四并发，提示词显式包含“八方旅人2”；第二轮选择A作为1254×1254不透明石灰岩底材。源PNG逐字节复制，无脚本改图，开启mipmaps、无尺寸限制。完整提示词及候选路径见 `assets-v61-prompts.md`。
- 裸地岩石和实体岩块共用 `meadow_mineral.gdshaderinc` 的8米世界取样与矿物色场。四条旧崖纹仍按64%参与各自断面细节，未冒称它们为无光照albedo；原先91%的预绘细节占比降低。近景五块石头保持实体轮廓、碰撞和真实方向投影。
- 程序地形、碎石、草甸、前景等分开固定随机种子，避免下次改岩壁时带动所有草木重排。本版相对v60有一次程序分布变化，**不声称六组网格全部未改**。独立PNG道具仍不重复。
- `MeadowColony_01` 向后移0.5米到(-14.20,-38.14)，修复高度场修改后原根点高出真实表面的问题。移动在原局部范围，不占用行走/Boss空间。
- 缓存改为 `assets/baked/v61/`，完整预览脚本增加 `outcrop-check`，默认导出v61。旧v60包、源码快照和未选素材均保留。
