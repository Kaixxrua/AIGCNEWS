## 条纹根因的Web对照

换底材之后，草地和没有使用该草图的道路上仍有规律斜纹。默认面板同相位对照：

| 临时条件 | 目视结果 |
| --- | --- |
| 0.25法线偏移、真实投影开启 | 草地和道路仍有成排暗条 |
| 关闭方向投影 | 成排暗条消失，说明不能只归因于草纹理 |
| 0.70法线偏移，0.025深度偏移 | 条纹减轻但仍可见 |
| 1.30法线偏移，0.025深度偏移 | 地表明显更干净，树、岩石、桥下投影仍保留 |
| 0.80法线偏移，0.060深度偏移 | 残留条纹，不选 |

最终选1.3，再检查月夜根部与投影，没有以关闭阴影解决问题。判断为低偏移导致的阴影自遮挡伪影，与Godot说明一致；偏移过大也可能导致投影脱离物体，需继续在新增地形上复查。Compatibility模式开关阴影还会改变光照颜色处理，因此此对照只用来定位条纹，**不把两张图亮度变化当作改进证据**。[Godot官方光照与阴影说明](https://docs.godotengine.org/en/stable/tutorials/3d/lights_and_shadows.html)。

对照原图保存在 `artifacts/v60/day-candidate-a.jpg`、`day-no-shadow-diagnostic.jpg`、`day-bias-070-diagnostic.jpg`、`day-bias-130-diagnostic.jpg`、`day-bias-080-depth-0060.jpg`、`night-bias-130-diagnostic.jpg`。诊断画面不是最终交付包。
