# v65：近景受光、天空补光与近灯遮挡

2026-09-10。用户新增要求：光影更好、更真实。本轮针对现有网页场景做光影修正，不换引擎、不改相机，不增加大纹理，不用额外景深模糊掩盖资产连接。

## 实现与取舍

- 近景独立道具的绘制补色由0.10降至0.035，主要交给实际光源着色。近景使用Burley漫反射，只有叶片启用0.10透光项，木石/灯柱不再统一套用叶片背光。远林少量既有绘制补色仍保留，不声称所有图片已成为全三维材质。
- 白天均匀环境光0.34→0.30，有方向的冷色天空补光0.26→0.34；夜间均匀环境光0.48→0.40，冷色补光0.30→0.38。主阳光1.64、主月光1.10及原曝光不提高，窗灯、月鹿、光源位置和昼夜时长不变。这是便宜的定向补光近似，不是动态全局光照。
- 保留4096阴影贴图、两个级联、118米范围与已验证无条纹的1.3法线偏移；设置中等阴影滤波，阴影扩散参数2.0→1.65。接触遮蔽半径0.72→0.52、强度1.70→1.45，收紧宽黑边，不提高景深模糊。
- 只为近处主路灯开启夜间局部投影，7.2米照明范围不变、阴影不透明度0.82。白天关闭它的投影；其他七处路灯/窗群保持轻量照地光，52处窗格光晕及月鹿随行光保留，不把所有灯都改成实时投影灯。
- 第一轮所有贴片都改用Burley后，白天远城变灰暗，虽然19阶段检查通过，仍未采用。保存 `day-candidate.jpg`、`night-candidate.jpg` 和 `unified-burley-candidate.pck`。第二轮将远景恢复原有宽漫反射；近/远两个小着色器共享 `meadow_cutout_surface.gdshaderinc`，透明边缘、窗灯覆盖、风摆与夜色逻辑不分叉。
- 新增 `tools/audit_lighting.gd`：检查38个近景植物与4个近处非植物道具的受光设置、日夜端点、一组夜间局部投影的预算，以及v64六组静态网格全部数组/变换完全相同。缓存升级至v65。

原生能力依据：[Godot环境与后处理文档](https://docs.godotengine.org/en/stable/tutorials/3d/environment_and_post_processing.html)说明Compatibility从4.6起有简化SSAO，只提供半径和强度调节；[渲染器对照](https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html)区分了网页Compatibility与Forward+的GI/PCSS能力。本轮没有把不支持的高级特效开关当成实际效果。

本轮是有针对性的光影改善，不是光线追踪、动态GI或整体美术验收。近处树木仍是带绘制明暗的2.5D资产，远山/城镇也不是可环绕的完整模型；光照可以改善协调，但不能凭调光消除全部原画透视/体积限制。上游河岸与草根、水边的硬接仍是后续内容，中央行走和Boss空间保持。
