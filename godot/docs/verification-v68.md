# v68：实体河岸分层与日夜受光保留

2026-09-10。继续用户“白天和晚上都更自然，但不能太暗”的方向。本轮不是再次抬高曝光，而是修正岸坡大形、岩面材质与真实表面朝向。场景仍是HD-2D方向的2.5D游戏场景，不是完整可环绕的写实世界。

## 具体改动

- 将局部河岸的单一平滑坡肩改为三段实际高度台阶，配合不等距侵蚀凹口与沿河弯曲轮廓。同步重分配原有岸线采样，保留92,619顶点/184,000三角形和索引拓扑。桥与入口、前景外缘、远城及中央活动区不在本轮地形编辑范围内。
- 水面宽度跟随凹口扩大，地被/岸石重新落在真实高度上。低于水位的植被排除仅作用于河流足迹，不误删同样低海拔的干燥前景岩脚。
- 移除编辑范围内会跨越新台阶的旧细碎覆盖岩体；区域外保留90块沿坡岩体，36个分布引导区，2,096个精确表面根点，共58,812个额外三角形、两批网格。旧河石顺新地形采样为113块，非河石数量保留。
- 使用内置imagegen四并发生成岩岸材质，每条提示词明确包含“八方旅人2”；选C。新资产为1254×1254全幅不透明材质，非棋盘格/透明切片，保留原始PNG并启用mipmaps。77张既有PNG逐SHA-256不变，新加一张，详见 `imagegen-riverbank-v68.md`。
- 岩岸以世界米尺度取样，干湿响应和小幅凹凸参与真实日/月光；不把完整预照明风景覆盖到河边。材质保留少量生成的裂缝暗部，因此不宣称它是扫描PBR全套贴图。
- 只在新雕刻岸坡上恢复实际三角面的法线方向，避免台阶两端的平滑高度函数法线把陡面照成平坡。没有用新增模糊或全屏染色掩盖接缝。
