# v83 — 修复网页里星星看不清

用户明确反馈 v82 普通网页看不见星星，因此原生 2K 原图里能找出细点不再作为充分验收条件。本轮只改星点参数：主星比例约 6%→14%，半径上限 .135→.195，普通星强度 .40–.75，主星再加 1.60。星位、占位密度、云后置遮挡、天空底色、夜间照明、水和景深不变；不是压暗场景以增加反差。

## 已验证

- 唯一命令 73801 实际 exit 0：专项 `audit_sky_stars.gd` 和 `20260910-154109-*` 材料流程 10 阶段完成，12 份日志无 ERROR/WARNING。原独立边界 `.195 ≤ .22 < .23` 通过，未修改审计或门槛；暂停/渐变/反向/端点及非星空源保护通过。未重跑完整 35 阶段，也未把三个 parse-only 探针当成真实 GPU 测试。
- 两名只读代理确认：相比冻结 v82，仅主星阈值、半径、强度及注释改变；占位/位置、运算结构、循环和 pass 数未增。
- 新独立网页标签完成实际 WebGL 加载，1920×1080/DPR1.5 下记录就绪 28,447ms、下载 1,988ms、场景构建 5,479ms；切夜、播放正常，console warn/error 为空。此数不是严格同环境冷/热 A/B 性能结论。
- `artifacts/v83/night-visible-stars-2k.png` 已解码验证 PNG 2560×1440；保存时 canvas 同尺寸、DPR≈1、暂停 clock 0、night blend 1，完整构图，未经放大或裁切。主代理 original 整幅确认：城堡两侧及云间主星更明显，不需要逐点寻找；未靠改变地面亮度衬托。截图后已恢复普通 viewport/device metrics，并将网页切到夜景播放状态。
- v82 的旧标签连续加载异常仍保留为未确证根因的问题。本轮没有宣称其根因已解决；v83 普通独立标签能加载和运行，不等于长时间压力测试完成。
- 独立视觉代理最终确认：v83 主星整幅可辨、不杂乱、不抢地灯，夜亮和水面无明显变化；但左上大云边缘及上方中部小云团仍有亮点贴云面的观感。因此只接受主星可读性修复，不把半透明云边缘的融合效果无条件判为通过，后续仍需细化。
