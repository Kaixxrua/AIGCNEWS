# v72：建筑朝向根因与分区受光

2026-09-10。继续向整体协调、清晰日夜与自然资产衔接推进，完整美术目标尚未完成。

## 发现的根因

最初看到城堡/村庄仍有较强固定补色：`painted_fill=0.60`、平面法线及Lambert wrap。配置了对应原图屋顶/塔身/墙面的分区法线，改为Burley并降低固定补色后，第一轮实际网页出现主体白天偏暗、少数屋顶突亮、建筑夜间异常亮的问题，未接受为最终效果。

独立WebGL读回给出了方向反转的证据：未分区控制墙面直射日光为0，直射月光为0.641525；三处屋顶的旧法线日光也是0，月光却为0.114062。分区法线的日光0.111308/月光0.029817与旧法线表现相反，原定直接光测试失败，没有放宽阈值。

进一步检查实际索引、顶点和法线：原生QuadMesh的两个面，其几何叉积与法线点积均为负；城堡6,450面及村庄3,300面却全部为正。[Godot ArrayMesh官方说明](https://docs.godotengine.org/en/stable/classes/class_arraymesh.html)规定三角形正面使用顺时针顺序。原建筑面序反了，双面材质在背面翻转法线，大量固定补色曾掩盖这种错误。

修正仅交换这9,750个三角形的索引顺序，不挪顶点、不改UV或图片，不改变地基、构图、窗口与风车轴心。新增回归逐面要求叉积与+Z法线方向匹配，并在真实GPU测试中要求控制墙面接受日光、不从背面接受月光。

## 建筑表面处理

- 城堡与村庄各32个源图坐标分区，使用屋面法线、圆柱塔身或圆锥屋顶的近似朝向。保留原砖石/窗口细节；着色器内只做有限幅度的旧绘制阳光补偿，不改PNG。
- 固定补色0.60→0.32，建筑使用Burley漫反射，根部接触系数0.20。纠正面序后实景白天略白、夜间偏暗，第二轮将城堡/村庄图像材质曝光从1.02/0.92收至0.94/0.84。
- 新增夜间专用的冷色定向天空补光：旋转(-35,24,0)、颜色(0.53,0.66,0.87)、能量0.70，随实际night_blend渐变，白天为0。通过独立渲染层仅影响城堡、村庄及两个叶轮，保留它们原有层；不额外生成阴影图。全场的日夜主光、曝光、AgX、雾、景深、水、天空和动物逻辑未改。该补光是美术化的间接光近似，不是物理GI。
- 它仍是2.5D美术网格与近似分区法线，不是完整可环绕的三维建筑或动态GI。64分区不等于城镇每个建筑表面都已重建。
- 首轮四处尖屋顶分区越过透明轮廓，被注册检查拦下。按原PNG逐列alpha边界重测并修正，未放宽不透明覆盖阈值。最终4,012个分区样点，最小覆盖0.926；这验证取样位置，不是整体艺术相似度评分。
