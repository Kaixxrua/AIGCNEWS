## 实现

- 云改为 8 组、共 48 个软椭球密度体的沿视线解析近似；取消离散 ray march 步进和像素抖动，避免条带被替换成噪点。各组漂移保持形态，共用可暂停时钟。仍是风格化体积近似，不是完整气象散射/自遮挡模拟。
- 近景范围 23–43m → 16–32m，最大半径 8 → 3px；远景起点 215 → 300m，最大半径 0.35 → 0.15px（1080 渲染高度基准）。建筑两处均不再额外虚化，普通素材 mip bias=-0.25，建筑=-0.45，保留 mipmaps。
- 白天/夜晚雾密度 0.00042/0.00048。月方向光 1.10，弱冷色反射方向补光 0.30；夜环境光 0.48，曝光 1.15。已撤销实验中的高环境光/曝光和额外暗部统一抬升；亮度来自方向月光与有出处的局部灯光。保留较低道路夜间反射率与冷色夜间材质响应。
- 四并发选 C，新增三件各用一次的道路灯具，分别靠近左侧岔路、桥头、远处路弯。玻璃位置逐张按 UV 测量，各有实际 OmniLight3D 暖光池与深度测试柔光晕。加上旧灯笼、四处城镇/村庄窗口群灯，共 8 个局部点光源；不为 52 个窗户各增加一盏实时灯。52 暖窗及其光晕保留，合计 56 个光晕。
- 美术伪球形法线强度 0.75 → 0.38；树林和建筑绘制补光降低，更多响应公共受光。每个近中景素材根部采样 5×5 地形高度、温和接触压暗。新增 2,326 个真实地形/岩面短草根点，每点三叶，一个额外 mesh，避开主路/Boss/河流，遮住硬接缝。当前总计 122,897 个草/叶形体。
- 四并发选 B 的动物图集：野兔、小鹿、狐狸各一只，每只四个动作帧，独立停留/随机换路/短程跑动。自然比例、实际世界尺寸，接受公共日夜照明、深度遮挡和影子。栖息区避开中央路、Boss 空地、河水、陡坡、树干及实体岩块；路径按 0.25m 分段检查，还检查身体宽度，不只看终点。动物脚底逐帧从地形与岩石三角面取最高支撑。
- 四并发选 C 的四帧飞龙图集：真实世界椭圆轨道，z=-297..-273m，位于 z=-255m 的城堡之后。38 秒一圈，振翅与滑翔交替，转弯轻微倾斜；各帧以肩部锚点对齐，避免图集留白差异产生跳动。不在屏幕上贴固定大小图标。
- 生物统一读取已有环境时钟，暂停后位置与帧不动，暂停时仍可昼夜切换，恢复不补跳。不是新建战斗系统或完整导航系统。
- v51 透明河水、72 个水下石头保留。75 个独立图像元素，各放置一次；新图集三个区域/三个生物/一条龙互不重叠复用。源 PNG 逐字节复制，不脚本抠图、去白边或绘制替代素材。
