# v73：替换突兀草本，原生图集与曲面接地

2026-09-10。上一轮v72修复了远建筑反向受光，本轮继续推进整体素材协调；完整美术目标尚未完成。

## 目视诊断与选择

重新对照用户晴天参考及v72普通网页：`RoadsideGrass`原图有明显独立土垫、圆团轮廓和偏插画的细描高光，缩小后像单独摆放的盆景；`Wildflowers`也带大块土垫与金色预绘光晕。不能用更多景深、雾或整体压暗解决素材差异。

使用内置ImageGen四并发，提示词显式包含“八方旅人2 / Octopath Traveler 2”，选A的两种独立低草本图集。完整提示词、四张候选及透明统计见`imagegen-herbs-v73.md`。新PNG原尺寸1916×821，原生alpha，79.483%像素全透明，可见红色杂边计数0。逐字节复制后不改写像素，开启mipmaps，不设置尺寸上限；旧两张PNG保留源码中，不再进入当前主场景/显式导出资源。

## 场景实现

- 两个不重叠UV裁切区域，每种只使用一次。草丛保持原脚点与4米宽度；花丛保留5.4米宽度，由(10,-3)移至(13.5,-4.5)，向河岸侧收拢并让出道路。按原图宽高比计算高度，不单独压扁纵轴。
- 每处网格48×24格，底缘按源图49列采样，90个有实际可见植物的支撑点。网格浅弯深度分别0.52/0.702米；下部随真实地形起伏，上部轮廓保留。UV覆盖完整0–1，底缘以下的透明/细叶区未从图像中裁掉。总4,608个三角形；它仍是浅曲面2.5D资产，不是每片叶子都有独立体积的完整三维植物。
- 共享实际日光/月光、Burley材质、投影与接触遮蔽，固定补色0.035；材质曝光0.87、对比1.06、细部法线强度0.18。新图不使用去白底色键。没有改全局曝光、主光、天空、景深、水或建筑参数。
- 实测根行写入零风权重；上部保留轻摆。动物障碍使用沿真实曲面脚线的一串小范围圆形，避免新草本占地被当成空地。栖息区范围和行走/Boss地面保持。
- 已有低草仍留在原地：为两处图像资产记录独立的旧低草采样原点，避免换花丛位置时重新随机排列整幅草原的低草。它不是旧图像的重复使用；原有低草几何仍是独立真实叶片。
